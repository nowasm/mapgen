# 固定门样式设计

## 目标

地下城中的门不再随机选择外观，而是由全局房间角落样式唯一决定：`column` 使用方形门框和 `door-rotate-square-c`，`diagonal` 与 `round` 使用圆形门框和 `door-rotate-round-c`。门的开启状态仍由 `doorOpenRate` 控制。所有入口都只生成一片门扇，并始终保持原始窄门框和门扇尺寸；即使通道较宽，也由门位两侧和门框上方的墙体补齐开口，不拉伸门资源。

## 数据与生成

从 `DungeonParameters` 和 `ResolvedDungeonParameters` 删除 `doorStyleWeights`，参数面板同步移除入口样式权重。布局中的门只保留位置、朝向和开启状态，不再保存外观样式。模块构建根据 `roomCornerStyle` 固定输出方形 C 或圆形 C 系列，门框固定为原生 2 米宽、2.4 米高，门扇固定为原生 0.925 米宽、2.1 米高、0.25 米厚。房间墙只扣除 2 米门槽，并在门框上方补齐至 3.2 米墙高。

这样门的外观不会消耗随机数，同一种角落模式下全图门型完全一致；Seed 仍确定性生成布局与开关状态，GLB 和布局 JSON 中的门模块都能直接追溯到对应的 C 型门资源。

## 验证

- schema 拒绝遗留的 `doorStyleWeights`，默认与 resolved 参数均不再包含该字段；
- 多个 Seed 和开关状态下，`column` 只出现方形门框与 `door-square-c`，另两种角落只出现圆形门框与 `door-round-c`；
- 宽通道也只使用原生窄门，开启时绕侧边铰链向房间内部旋转，关闭时保留与原始门扇等大的碰撞；
- 浏览器参数面板不再显示入口权重，固定样例通过 Godot 无头导入测试。
