# ADR-0004：离线转换并可追溯地复用 VOX 资源

## 状态

已接受，2026-08-13。

## 背景

参考仓库包含可用于地牢外观的 `.vox` 文件和 JSON 子模型映射。浏览器和 Godot 不应在
每次生成或导入时解析来源格式；同时，迁移资源必须保留许可、来源和转换可复现性。

## 决策

建立独立离线转换工具。它验证 VOX 方言和资源映射，提取经筛选的默认地牢模块，优化网格，
输出一个 GLB 模块包和一个带来源哈希、枢轴、方向及包围盒的目录 JSON。复制资源前完成
许可审查，并在新仓库保留所需 LICENSE、NOTICE 与逐文件来源清单。

## 结果

### 正面

- 网页生成和 Godot 导入只处理标准 GLB 与项目 JSON。
- 原始资源不被原地修改，转换过程可重放和审计。
- 可用模块黄金测试捕获枢轴、缩放或调色板错误。

### 负面

- 需要理解可能为定制方言的 VOX 文件。
- 转换器和来源清单增加一次性工程量。
- 原资源更新后必须显式重新转换。

### 中性

- 阶段 1 使用程序化占位模块，不让资源研究阻塞端到端管线。

## 备选方案

- **运行时解析 VOX**：减少预处理，但会把格式复杂度带入网页和 Godot 两端。
- **完全重做美术**：许可边界简单，但不满足优先复用现有资源的要求。
- **手工逐个导出**：短期可行，但不可复现，且易丢失来源和统一坐标约定。
