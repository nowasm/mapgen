# ADR-0003：采用图优先的约束二维布局算法

## 状态

已接受，2026-08-13。

## 背景

生成器需要明确支持 Hub、Ring、Branch 三种结构，并控制环路、死胡同、线性翼和受保护
分支。仅用 BSP 容易得到规则矩形分区，无约束随机放置则难以稳定保证可达性和模式特征。

## 决策

先生成带受保护主路径的房间连接图，再为房间分配尺寸并在整数 XZ 网格内约束放置，最后
用直线、L 形或避障走廊实现图中的边。所有尝试均使用确定性随机流和有限预算。

## 结果

### 正面

- 拓扑模式和参数有直接、可测试的语义。
- 连通性在空间放置前成立，便于诊断和修复。
- 房间图可用于预览、调试以及未来扩展房间功能。

### 负面

- 图可行不代表空间一定可放置，需要回溯和重试。
- 参数组合极端时，生成成本可能高于 BSP。
- 需要明确避障、净空和降级规则以保持确定性。

### 中性

- 目标是行为与风格相当，不复原缺失的 `mapimggen.exe` 内部实现。

## 备选方案

- **BSP**：快速稳定，但难自然表达环形和中心枢纽拓扑。
- **随机房间 + 最近邻连接**：实现简单，但结构控制弱、失败率和风格漂移较大。
- **Wave Function Collapse**：适合局部模块约束，但不适合直接控制全局房间图。
