# ADR-0007：使用 Kenney Building Kit 独立模块拼装地牢

## 状态

已接受；替代 ADR-0006。

## 背景

Kenney Modular Cave Kit 的房间主要是固定尺寸的整体模型。对程序化地牢而言，这会约束房间尺寸、圆角半径和门位，并需要额外几何去修补预制模型中的开口。项目需要在保持任意布局参数的同时，导出可在 Godot 中使用的完整 GLB 与碰撞数据。

## 决策

默认视觉资源改为 `assets/kenney_building-kit`，使用其 2 米独立地板、直墙、立柱直角/削角/圆角、方拱/圆拱门框和门扇进行语义化拼装。生成器不再发出固定房间或走廊 shell。`roomCornerStyle` 是全局房间角落三选一参数；门固定为原始尺寸的单开 C 型窄门，`column` 使用方门，另两种角落使用圆门，并向所属房间内部开启。通道宽度不改变门资源尺寸。

## 后果

### 正面

- 房间尺寸、门位与布局参数不再受 prefab 限制。
- 三种角落墙、匹配的角落地板和门洞使用同一套原生模块，边界可闭合。
- 单个模块具有明确语义，后续在 Godot 中替换、隐藏或扩展更容易。
- Building Kit 的 CC0 colormap 可烘焙为顶点色，GLB 无外部贴图依赖。

### 负面

- 模块数量和导出节点数会增加。
- 非 2 米余数槽位仍需轻微缩放。
- 圆弧碰撞由多段盒体近似，不是逐三角形碰撞。

### 中性

- 旧 Cave Kit 资源和转换脚本可保留作历史对比，但不再被默认运行时引用。

## 备选方案

**继续使用 Cave Kit 整房模型**

- 拒绝：无法可靠适配任意房间尺寸和门位。

**只拉伸一个直墙模型**

- 拒绝：比例和表面细节失真，圆角仍需程序化替代品。

**完全程序化几何与自制材质**

- 暂不采用：会失去用户指定的 Kenney 资源外观与可复用模块。
