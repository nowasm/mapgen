# ADR-0005：原生 Kenney 房间预设与程序化布局混合生成

## 状态

部分被 ADR-0006 取代

## 背景

生成器需要允许房间四周呈圆形或圆角，同时尽量使用 Kenney Modular Dungeon Kit 2.1 的完整房间、走廊、门和变体资源。现有布局支持任意矩形尺寸和任意正交连接；直接非等比缩放完整房间会拉伸石块，完全程序化弧墙又无法发挥资源包的完整房间模型。

系统仍需保持确定性 Seed、单层无屋顶、可行走碰撞、自包含 GLB 和 Godot 固定烘焙。

## 决策

- 保留矩形程序化房间，同时增加原生尺寸的 `room-small`（12×12）、`room-large`（20×20）和 `room-wide`（20×12）预设及其 variation。
- 通过布尔参数 `roundedRooms` 控制全图房间形态：关闭时全部为矩形，开启时全部选择原生圆形/圆角预设；`roomVariationRate` 继续控制变体比例。预设只在当前大格与房间尺寸约束容许时选择，不做非等比拉伸。
- 圆形房间保留原生模型的地板与低矮细节，墙体使用 Kenney 墙段沿圆角周界连续铺设，只在真实门位移除墙段。
- 圆形房间碰撞与可见墙共用同一组分段圆角周界盒；地板继续使用简单静态碰撞。
- 直走廊保留 `corridor` / `corridor-wide` 的原生地板，沿两条长边单独铺设可见墙与碰撞；矩形房间继续使用地板和墙体模块变体。
- 门型资源选择已由 ADR-0006 迁移到 Cave Kit；开启方向仍由相邻房间决定。

## 影响

### 正面

- 圆形房间保持 Kenney 原生比例和美术细节。
- 现有拓扑、碰撞、导出和 Godot 烘焙协议继续适用。
- 单层地图中有意义的房间、走廊、门和表面变体得到更高覆盖率。

### 负面

- 完整房间模型会增加视觉包和网页包体积。
- 圆角墙由短直墙段近似，需要回归测试和视觉检查。
- 原生预设限制圆形房间尺寸，不能连续任意缩放。

### 中性

- 楼梯和带洞地板留到多层地图阶段，避免当前单层碰撞产生无意义落差。

## 备选方案

- 任意非等比缩放完整房间：因模型和纹理细节明显拉伸而否决。
- 完全程序化圆墙：自由度高，但无法充分使用完整 Kenney 房间资源。
- 只使用固定整张 prefab 地图：会丢失当前布局和参数控制能力。
